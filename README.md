# CARDAPIO-ONLINE

DESENVOLVIMENTO DE SISTEMA DE DELIVERY DA STAR BURGUER, PROJETO COMPLETO UTILIZANDO AS TECNOLOGIAS HTML, CSS, JAVASCRIPT, JSON, TAILWIND CSS, Toastify JS. 

<br>

SISTEMA FULL-STACK QUE TEM COMO OBJETIVO AUXILIAR COMÉRCIOS DE DELIVERY COM AS FUNCIONALIDADES QUE OTIMIZÃO OS PROCESSOS DE PEDIDOS E SISTEMAS DE ACOMPANHAMENTO DE PEDIDOS E ENTREGAS, PROVENDO MAIOR CONTROLE ADMINISTRATIVO SOBRE OS PEDIDOS.

<br>
<br>

***

## DESCRIÇÃO

SOLUÇÕES TECNOLOGICAS NASCEM DE FORMA PENSADA, PROJETADA, E DESENVOLVIDA PARA OTIMIZAR A AÇÃO HUMANA.

<br>

A APLICAÇÃO PERMITE QUE CLIENTES REALIZEM SEUS PEDIDOS DE FORMA PRATICA, RAPIDA E FUNCIONAL.

<br>

ESSE PROJETO CONTA COM FUNCIONALIDADES DE LISTA DE PRODUTOS:

<br>

*ADICIONAR ITENS AO CARRINHO
*VERIFICAR ITENS NO CARRINHO PELA HOME
*ACESSAR DETALHES DO CARRINHO
*REMOVER ITEM DO CARRINHO
*ADICIONAR E VERIFICAR ENDEREÇO
*VALIDAR SE O RESTAURANTE ESTÁ ABERTO
*ENVIAR PEDIDO PELO WATTSAPP (CONSUMO DE API)
